# Note by SP 🧡

เว็บบันทึกและสรุปบทเรียนรายวัน ธีมครีมส้ม พร้อม Dashboard, Calendar, Notes, Subjects, Login และ PostgreSQL

## เริ่มใช้งาน
1. คัดลอก `.env.example` เป็น `.env` และเปลี่ยน `SECRET_KEY` ให้ปลอดภัย
2. ติดตั้ง Docker Desktop
3. รัน `docker compose up --build`
4. เปิด http://localhost:5173 และดู API ที่ http://localhost:8000/docs

> Starter version สำหรับพัฒนาต่อ ไม่ควรเปิดบริการสาธารณะโดยไม่ตั้งค่าความปลอดภัยเพิ่มเติม
